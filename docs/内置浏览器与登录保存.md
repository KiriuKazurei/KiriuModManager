# 内置浏览器与登录保存

更新日期：2026-10-13，源码版本保持 **0.0.3**。

## 使用方式

在“获取Mod”的 GameBanana 网页中正常登录即可。绝区零和终末地共用一个浏览器、Cookie、网站本地存储与导航历史；切换游戏只打开对应的 games/19567 或 games/21842 主页。离开“获取Mod”隐藏视图，返回继续当前页面。关闭程序后再次启动恢复 Cookie；账户是否仍然有效由网站决定，网站退出登录会清除对应记录。

## 实现与兼容

- 继续使用原来的 `persist:kmm-gamebanana` 会话分区，保留已有网站 Cookie 和本地存储，不更换或清空旧登录数据。管理器页面仍使用独立桌面会话。
- `ModBrowser` 只创建一个无 preload、无 Node 权限的沙箱 `WebContentsView`。两游戏共用历史，后退可能回到另一游戏页面；主页按钮按当前选中游戏返回固定主页。
- 带有效期的 Cookie 由 Chromium 持久化，按网站有效期处理，不人为延长。GameBanana 域及其子域的会话 Cookie 由主进程 `GameBananaCookies` 使用 Electron 异步 `safeStorage` 加密，保存到用户数据目录下的 `gamebanana-session-cookies.json`。临时写入文件同样只有密文。
- 在首次加载网站前恢复会话 Cookie，保留 HttpOnly、Secure、SameSite、路径和 host-only/domain 范围。已有原生 Cookie 优先，不使用旧快照覆盖当前 Cookie；其它网站与有过期时间的 Cookie 不进入会话恢复记录。
- Cookie 变化、登录轮换和退出删除进入串行保存队列，正常退出前关闭网页、等待保存并刷新原生存储。加密或文件保存失败时显示固定提示，不回退到明文保存，不把 Cookie 内容写入日志或桌面接口。
- GameBanana 元数据请求、两游戏下载与页面使用同一个会话和 ModDownloads 流程。下载请求记录当时的来源游戏，详情必须匹配 19567/21842；安装、角色匹配、缓存和重试按任务游戏执行，使用该游戏设置目录，跨游戏重试复用视图且不切走当前网页。下载完成等待一键安装，安装后默认停用；“查看已安装 Mod”打开该任务游戏的库。

Electron [Cookie 文档](https://www.electronjs.org/docs/latest/api/cookies)说明未设置 expirationDate 的 Cookie 不跨会话保留；因此仅 `persist:` 分区不足以覆盖这类登录。[safeStorage 文档](https://www.electronjs.org/docs/latest/api/safe-storage)说明本机系统加密及异步接口；Windows 使用 DPAPI。无需保存账号密码或新增自建账号后台。
