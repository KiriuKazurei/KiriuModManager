# 通用提醒窗口

界面的一次性操作反馈使用 `showNotice()` / `confirmNotice()`，也可通过 `window.kmmNotice.show()` / `.confirm()` 调用。`FeedbackNotice` 将已有操作状态接入同一入口。持续进度、检测报告和历史记录保持在对应页面。

```ts
await window.kmmNotice.show({
  tone: 'success', // info | success | warning | error
  title: '操作完成',
  message: '配置已保存。',
}); // 默认一个“确定”按钮，返回 0

const choice = await window.kmmNotice.show({
  title: '确认操作', tone: 'warning', message: '是否继续？',
  detail: '可选的补充说明，保留换行。',
  buttons: ['取消', '继续'], defaultButton: 0, cancelButton: 0,
}); // 返回点击的按钮索引 0 或 1

if (await window.kmmNotice.confirm('放弃未保存的编辑？')) {
  // 用户选择了第二个按钮。
}
```

按钮只允许一个或两个；标题、正文、补充说明和按钮文字均作为纯文本渲染。多个提醒依次显示，相同的待处理提醒合并。Escape 返回 `cancelButton`，Tab 限定在弹窗内，关闭后恢复此前控件焦点。长内容在弹窗内滚动，主窗口与快速管理浮窗各有独立队列；内置网页在提醒显示期间暂停显示，关闭提醒后恢复。

`launchXXMI()` 返回 `{status, message}`：`submitted` 表示 Windows 已确认提交启动，`unconfirmed` 表示未收到确认，应显示提醒并让用户检查实际窗口。它不证明游戏或 Mod 的运行结果。Windows helper 的回执使用独立临时文件，不与 Launcher 的 stdout/stderr 共用通道；权限取消、明确的 Windows 启动错误仍分别报告。
