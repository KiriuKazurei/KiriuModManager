## 发现与处理

### 配置切换预览过早失效

复现：配置包含需确认的组件版本提示，首次应用未带确认时返回提示；用户接受并使用同一预览重试，原实现已删除预览凭证，因而报“配置切换预览已过期”。

修复：`ProfileService.apply` 在依赖确认通过、准备进入写操作时才消费预览凭证。显式取消仍立即使凭证失效，成功后不能重复执行。目录／内容／策略变化和到期检查继续保留。

新增两项回归：双游戏未接受时无 INI／库写入、无新备份，接受后可重试且只提交一次；显式取消不写文件、不创建备份且不能复用。对应[修复前失败](../.run-data/v004-verification/2026-10-14-c91631e6/profile-warning-before.log)、[修复后专项](../.run-data/v004-verification/2026-10-14-c91631e6/profile-warning-after.log)。最新窗口还实际点击了两游戏版本提示的取消与接受。

### 运行环境与旧脚本

- 沙箱首轮 151 项中 145 通过，跨盘／联接等六项失败；Electron 也无法在该沙箱内启动。保留日志后在沙箱外运行隔离样本，原有 151 项全部通过，修复后的完整 153 项全部通过。没有跳过这些测试。
- 中断恢复脚本仍查找旧的直接处理按钮及确认文案，已按当前“预览中断处理 → 确认处理中断操作”更新；核对预览不写文件、原生确认范围、原文件／稳定 ID 回退、新内容副本保留和重启。
- 关于页脚本仍假设只有两个页签，已按“常规设置 → 诊断 → 关于”逐项核对键盘导航，保持两处未保存设置草稿。
- 一次批量预设运行中，名称“所选组合”保存为“所选组”。[首次失败现场](../.run-data/priority-smoke/run-FAhdC9/report.json)保留；原脚本重跑通过。增加主窗焦点、输入值及保存后完整中文名称核对后，连续三次通过。首次原因未确定，未据此修改产品名称处理逻辑；最终人工输入体验仍待后续验收。
