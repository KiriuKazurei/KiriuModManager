# 桌面接口文档

更新日期：2026-10-13。本文件是当前 KiriuModsManager 的权威桌面 API、调用规则与 Cursor 接入入口：**49 个异步调用 + 1 个事件订阅**。实际源位置、完整参数/返回类型、主进程服务入口与当前 renderer 消费者见[自动接口清单](desktop-api-inventory.json)。0.0.1 新增管理器更新器；本轮只为更新验证生成隔离测试包，不将其视为正式发行。

## 1. 契约与边界

生产调用为 `window.kmm` → typed preload → 受信任主进程 handler → 本地服务。只允许已注册主窗/浮窗的可信文档 main frame；拒绝其它窗口、子 frame 和导航后的来源。sandbox preload 仅运行时 require Electron，共享映射为 type-only。

```ts
type GameId = 'zzz' | 'endfield';
type Result<T> = { ok:true; value:T } | { ok:false; error:string };
type DesktopChange = { gameId:GameId; settingsChanged:boolean };
```

所有异步方法返回 `Promise<Result<T>>`，下表“结果”只写 T。成功、错误、取消、部分成功按本次 Result 判断；收到刷新事件不是成功证据。传入游戏必须有效，Mod/预设/恢复 ID 必须属于该游戏及当前已保存库上下文。生产 API 不接收任意来源导入/删除绝对路径或任意 EXE；原生选择器/确认在主进程。普通管理使用已保存路径，页面未保存路径只属于草稿。

相关文件读写及设置保存由主操作队列协调，通知在同操作内发送。状态、进度、窗口显示/退出等保持响应。没有 HTTP 产品后端；部署测试 HTTP fixture 是测试设施。启动/浏览器请求返回只表示提交，不证明窗口、游戏或 Mod 已加载。

## 3. 关键数据与正常调用规则

- Settings 为 version:1、selectedGame、games（两游戏 GamePaths）及可选 desktop。GamePaths 有 xxmiRoot/gameDirectory/modsDirectory；DesktopPreferences 有 marketUrl/updateUrl/closeToTray。旧 `saveSettings` 完整替换仍兼容，但已无页面消费者，不能把该旧调用称为并发安全。设置页和桌面设置已改用局部方法，在队列内读最新值再 merge/save。
- `saveGamePaths` patch 仅允许三个路径 string，trim 后空值或绝对目录、最大 32767 字符、无 NUL；不要求目录已存在、不自动同步 loader、不改变 selectedGame。改游戏选择调用 `selectGame`。
- `saveDesktopPreferences` patch 允许 marketUrl/updateUrl、boolean closeToTray 和新增可选 updateSourceUrl。前两 URL 可空或不含凭据的 HTTP(S)，支持 {gameId}；更新源可空或不含凭据、占位符和片段的 HTTPS。URL 最大 4096 字符、无换行/NUL。省略字段保留，空字符串清空；两 patch 都拒绝 {}、null、array、unknown、undefined、无效类型/值，整份验证失败不写文件也不广播，不提供部分成功或取消。
- DeploymentResult 明确 filesDeployed、ready、runtime、inspection、settings 与版本；文件完成但缺运行库时 ready:false。sync/deploy 保存对应游戏，保留其它游戏和偏好；同步外部配置保留 Secrets/其它 importer/INI 注释并创建真实副本。路径保存不是 loader 安装或游戏生效证明。
- LibrarySnapshot 包含 root、mods、warnings、分组及 loaderMatched/excludeMatched。ModEntry 的 id 稳定，name/relativePath 是实际目录，metadata 含分类/角色/外观/作者/说明；enabled 是包含停用祖先的有效状态，ownDisabled 与 disabledAncestors 单独提供。toggle(true) 遇停用祖先可拒绝；rename 真正改物理名且保留 ID；metadata 不移动文件；classify 才移动并允许空 appearance；碰撞不覆盖。
- 新发现/导入记录用注册分类推断已知分类单层、分类/角色两层（空外观）；未知短路径保持原角色/外观解释，三层沿用分类规则。既有 metadata 不重推断。addGroup 只保存分组。ImportResult 的 importedIds/errors 可以同时非空；同时展示成功数和完整错误，再采用 library；取消为 canceled:true。替换/移除留真实恢复副本。
- Mod 预览支持可解码 PNG/JPEG/WebP/GIF；自定义角色图仅可解码 PNG/JPEG、最大 10 MB，拒绝/取消保留图与引用。默认角色图资源可为 WebP，与自定义限制分开。成功返回快照，原生选择取消 value:null；读 cover 的 null 是无图片。
- Preset 用稳定 Mod ID→boolean；savePreset members:null 捕获当前状态。applyPreset 返回 library/issues/applied/conflicts：多个互斥启用请求须先选择，未选择时无文件修改；缺失或受阻成员报告、其它继续处理。非成员保持，唯与新启用成员互斥的非成员会停用并报告。candidate hash 只看实际有效启用 Mod/INI 的 TextureOverride/ShaderOverride 字面值，不等于渲染冲突结论。
- IniDocument 返回相对路径、文本、编码/BOM相关 encoding、换行、digest 和带行身份的 keys。saveIni 的 text 或 keys 都保留原编码/BOM/换行，keys 保留其它字段/注释；digest 陈旧拒绝。最终编码 Buffer 含 BOM/换行最多 4 MiB，超限在副本/写前拒绝，原文件和副本数保持。
- RecoveryItem 区分 INI、移除、替换、完整 snapshot 与需人工取回的 legacy。restore 原生取消为 null，成功恢复范围以所选记录为准，覆盖前保留副本；完整快照恢复当前游戏 Mod/角色图/路径/metadata/预设，保留其它游戏，不同步外部 XXMI。根上下文不符拒绝。

## 4. 唯一事件与草稿状态

`onDesktopChange(callback:(event:DesktopChange)=>void):()=>void` 对应 `desktop:changed`，返回解除订阅函数，卸载时调用。

gameId 始终表示通知发生时当前 selectedGame，并非操作参数游戏的回执。settingsChanged:true 是配置重读提示；设置完整/局部保存、切游戏、部署/同步及恢复沿既有规则发送。恢复取消也可能 true，不能推出一定写入。Mod 管理/图片、预设保存删除应用、INI保存和手动完整备份成功后沿既有 false 刷新规则；错误不广播。取消某些原生操作可能刷新，仍检查 Result。

事件用于重新读取实际数据，不授权清空同身份 dirty 草稿。外部更新未编辑字段采用新基线，明确编辑字段保留；自己提交后只接受提交且期间未再次编辑的字段。切 Mod/游戏/库根清旧身份。INI 外部更新仍保留本地文本，保存时 digest 保护；用户明确重读后才放弃原编辑。

## 5. Cursor 接入与当前完成状态

`SettingsPage` 保存配置调用 `saveGamePaths`，只提交当前游戏改过的路径。`DesktopSettings` 保存桌面设置调用 `saveDesktopPreferences`，只提交改过的偏好。没有改动时本地反馈「无待保存更改」，不发送空 patch。错误保留输入。成功后 `acceptSubmittedGamePaths` / `acceptSubmittedPreferences` 只接受本次提交、且等待期间没有再改过的字段；其它游戏和其余偏好草稿保留。`App` 继续用 `selectGame` 切换游戏，只在 `settingsChanged` 时重读完整 Settings 并与字段草稿合并。检测、同步和部署仍走原接口。

旧 `saveSettings` 保留完整替换。当前没有页面消费者，清单为 compatibility-only。迁移前源窗口 `.run-data/modules-review/phase4-patches/run-U6VyMQ/report.json` 的 frontendMigrated 为 false，只代表当时产物。当前页面验收见 `.run-data/cursor-acceptance/acceptance-report.json`。

部分导入在角色概览和 Mod 列表同时显示成功数与完整错误，并采用 `ImportResult.library`。角色封面和 Mod 预览开始新选择时清除旧成功提示，`value:null` 不显示已保存，原图与引用保持。证据 `.run-data/cursor-acceptance/run-nbjhfm/report.json`。

逐文件调用与验收矩阵见[接口调整说明](接口调整说明.md#p4已实现的兼容局部保存接口)。预设成员、快捷键字段等未覆盖草稿、GUI 视觉、真实游戏，以及用户延后的新包，仍未完成；已覆盖边界不扩大为全部验收。
