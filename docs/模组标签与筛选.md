# 模组标签与筛选

本轮为 `agent/mod-tags` 的开发改动，保留此前详情独立滚动、固定右侧布局、角色字号和整行选中高亮；没有发布或覆盖安装版。

## 使用

- 搜索框右侧的“筛选”打开筛选与排序浮层，包含启停状态、收藏、标签和原有最多三条件排序。列表不再保留独立排序行。
- 列表状态使用绿色实底表示启用，红色实底表示停用，祖先目录停用继续显示“父目录停用”。
- 详情中的“标签”可输入名称、选择背景色并添加。右键标签打开编辑浮层，可重命名、选背景色或删除；点击、回车及 Shift+F10 同样可进入编辑，Escape 关闭。
- 列表标签位于名称和状态之间，横向排列。根据实际可用宽度测量完整标签，放不下的部分通过“…”展开全部；浮层位于顶层，不被虚拟列表裁剪，不改变行高。
- 标签文字自动选择黑色或白色；颜色与名称均为可见信息，不单靠颜色区分。

## 数据与接口

每个 Mod 的实体文件夹保存 `tags.json`，随文件夹移动、改名和复制。格式如下：

```json
{
  "version": 1,
  "tags": [
    { "name": "夏装", "color": "#147744" },
    { "name": "高清材质", "color": "#174a99" }
  ]
}
```

最多 20 个标签，名称使用既有 NFC/去空格/忽略大小写去重规则，长度 1–40，禁止控制字符。颜色为六位十六进制值。文件必须是小于等于 32 KiB 的普通文件；无效 JSON、未知版本、重复名称和无效颜色拒绝读取或覆盖，并保留原文件。

存在 `tags.json` 时，以它为准；旧库没有该文件时继续读取 registry 的 `tags`，使用默认蓝色。扫描不会给旧模组创建 sidecar；第一次编辑时创建。空 `tags` 数组表示明确清空标签。

沿用 `operateMod(game, id, {kind:'tags', values, colors?})`，仍是完整标签集合更新；`colors` 为名称到颜色的字典，不接受集合以外的名称。旧调用不传颜色时，已有标签颜色保留，新标签使用默认色。`ModEntry.tagColors` 为可选字典，`ModEntry.tags` 保留字符串数组，搜索和筛选继续使用名称。

主进程使用 `mod-tags` 文件事务同时发布 sidecar 和库索引；失败可回退，进程中断沿用“备份与恢复”处理路径。此事务仅允许当前根目录内一个 Mod 的 `tags.json` 和当前游戏库索引，禁止 INI、资源或任意元数据路径。

替换模组内容和单模组内容恢复保留当前标签与颜色；完整快照恢复快照中的标签。两个游戏的 registry 和实体目录独立。替换、恢复时在已拥有的 incoming 副本写入保留标签，不修改原始来源或原始恢复副本。

## 界面契约

| 组件 | 参数和行为 |
| --- | --- |
| `ModLibraryFilters` | `status/onStatus`、`favorites/onFavorites`、`availableTags/tagFilters/onTags`、`tagQuery/onTagQuery`、`sort/onSort`；原生 auto popover，排序偏好继续按游戏写入 localStorage |
| `ModLibraryRow` | `mod, selected, checked, busy, onSelect, onCheck, onFavorite`；详情选择、批量复选、收藏和标签展开分别处理，避免嵌套按钮 |
| `ModTagList` | `mod:ModEntry`；ResizeObserver 测量可用宽度，显示完整前缀和可访问的展开按钮 |
| `ModTagsPanel` | `gameId, mod, busy, onBusy, onUpdated`；标签修改沿用生产 operateMod，错误走公共 Notice；添加草稿不被同 ID 刷新覆盖 |

`ModPage` 负责筛选、排序、选择和快照；`ModOrganizationPanel` 继续负责收藏与依赖，嵌入 `ModTagsPanel`。HTTP 和 IPC 通道数量未增加，消费者位置更新到自动接口清单。

## 验证入口

`tests/mod-tags.test.ts` 覆盖旧标签兼容、颜色校验、实体 JSON、复制后重建索引、外部修改、清空、跨游戏、重命名/移动/替换/恢复/快照和发布失败回退。

`node scripts/smoke-mod-tags.mjs` 启动隔离数据的真实 Electron 窗口，覆盖 200 项虚拟列表、标签添加与改色、重复名称、右键和键盘编辑、展开、筛选内排序、900/1180/1600 宽度、明暗主题、实际重启与删除持久化。其证据位于 `.run-data/mod-tags-smoke/run-*/report.json` 与对应截图。

其他门禁：`npm.cmd run typecheck`、`npm.cmd run build`、`npm.cmd run api:check`、`npm.cmd test`。源码/隔离窗口验证不代表安装包、Release 或真实游戏验收。
