# Kiriu Mod Manager 0.0.8

- 修复 GitHub 发布文件重定向导致的 `Redirect was cancelled`：更新器通过 Electron 原生请求逐跳读取重定向，再验证 HTTPS 地址，支持 GitHub 清单和 ZIP 的真实下载。
- 保留更新包大小、SHA256、仓库归属、版本及完整程序清单校验；支持下载中止和响应截断报错。
- 延续 0.0.7 的统一路径设置、EXE 路径验证与目录转换、可见字段提示，以及成功删除临时旧版、失败恢复并提示的更新流程。

0.0.6 / 0.0.7 已安装版本自身仍有更新请求缺陷；首次升级可能需要一次兼容接续或完整目录包。0.0.8 的更新器已修复这些已知问题。0.0.7 发布历史保留。
