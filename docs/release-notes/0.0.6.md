# Kiriu Mod Manager 0.0.6

- 新增统一日志系统：记录操作链路、后台任务、文件事务、界面异常和进程退出，支持关联追溯、敏感信息脱敏及日志轮转。
- 设置 → 诊断新增日志入口，可打开日志目录并分析冲突候选、下载／校验失败、磁盘不足、权限／占用及异常退出线索；默认存放在管理器安装目录的 log 文件夹。
- 新配置或空白 Mod 路径默认使用管理器目录下的 Mods/ZZZ 和 Mods/Endfield；保留已有自定义路径，在设置中清空路径可恢复默认值，不自动移动已有 Mod 或修改加载器配置。
- 管理器更新流程保留 Mods 和 log 用户目录，失败回退时一并恢复；更新包不得携带这两个目录。
- 主界面品牌显示为 ModManager，统一方形粗边框与主题色粗体 K；更新托盘／任务栏图标，浅色主题 Logo 使用灰蓝底色提高辨识度。

冲突候选与异常退出记录用于排查，不代表自动确认游戏渲染冲突或故障根因。源码更新不等同于可下载发行包；本次不包含 GitHub Release、便携包或真实游戏／XXMI 验收。
