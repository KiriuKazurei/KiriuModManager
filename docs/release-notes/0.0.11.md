# Kiriu Mod Manager 0.0.11

- 下载中心新增 Mod 包暂停与继续，支持新安装包和 Mod 更新包；暂停后保留进度，并可通过“已暂停”筛选。
- 重新打开管理器后可手动断点续传，保留原任务、所属游戏、安装目录与更新目标。下载期间定期保存校验片段，异常退出可从最后完整保存的位置恢复。
- 继续前核对本地片段、资源来源及服务器 Range 响应，沿用原登录会话；片段损坏、资源变化或服务器不支持时明确提示，由用户选择重试或重新下载。
- 已暂停任务释放下载名额，取消会清理该任务的恢复片段；下载完成后仍需校验及手动安装确认。

本次范围为 Mod 下载，管理器自身更新包不包含暂停／续传。

验证：302 项回归测试全部通过，类型、接口清单与构建检查通过。真实 Electron 隔离测试覆盖暂停后跨进程恢复、异常退出恢复、带会话 Cookie 的 Range 请求和实际下载页 IPC；更新器网络回归通过。未安装真实 Mod 或启动游戏。

使用与验证边界见[下载暂停与断点续传](../下载暂停与断点续传.md)。
