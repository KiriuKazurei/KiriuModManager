# Kiriu Mod Manager 0.0.2

- 新增“获取Mod”：内置浏览绝区零 GameBanana 页面，支持网页前进、后退、刷新和返回首页。
- 接管 GameBanana 托管的 ZIP、7z、RAR Mod 下载，独立页面管理进度、已下载资源与历史记录，支持取消、重试与查看缓存包。
- 下载校验后进入独立“下载进度”页面等待一键安装，自动匹配角色文件夹并允许逐项手动选择，安装后默认停用，绑定来源、作者、版本、站点 Mod/文件身份及文件信息。
- 安装目录使用设置中保存的绝区零 Mod 目录；目录变化时等待用户明确选择，不静默改装到另一目录或游戏。
- 多 Mod 包逐项处理，同名内容保留；有效站点绑定用于避免重复安装。
- 下载任务记录重启后可读取，中断任务不自动续装；与管理器更新安装协调。
- 主窗口标题栏随主题同色并隐藏标题文字；刷新和原“更多”入口统一移到设置页快捷操作。
- 保留已有批量管理、互斥组、预设、来源版本历史及恢复能力。

本版本不新增终末地网页、自建商店、网盘适配、Mod 自动版本升级或云同步。源码验证、真实网站联调、人工体验和正式发布状态分别记录在项目进度文档中。
