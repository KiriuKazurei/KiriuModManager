# Kiriu Mod Manager 0.0.3

- 终末地“获取Mod”接入指定 GameBanana 主页；绝区零和终末地共用一个浏览器、导航历史和 Cookie，切换游戏只切换主页链接。
- 记住 GameBanana 登录：普通 Cookie 按网站有效期持久化，会话 Cookie 在本机加密保存并在重启时恢复；网站退出登录后不恢复旧登录。
- 终末地与绝区零共用托管下载、大小/摘要校验、网站信息绑定和下载页一键安装；按任务所属游戏使用设置目录与角色匹配，安装后默认停用。“查看已安装 Mod”打开该任务所属游戏的库。
- 设置增加“常规设置”和“关于”分页。关于集中展示版本号、检查更新、获取更新、更新说明和现有更新源配置。
- 两个分页切换保留未保存的路径、桌面设置和更新源草稿，支持键盘导航。
- 保留同色无标题文字的主窗口标题栏，以及设置页快捷操作。
- 保留独立下载进度页、一键安装、角色文件夹匹配、手动位置选择和默认停用规则。

两游戏支持 GameBanana 托管 ZIP、7z、RAR，外部网盘仍需手动导入。管理器更新沿用既有确认、校验和退出安装流程；源码模式显示版本与检查入口，发行包中执行更新安装。
