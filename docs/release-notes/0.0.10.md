# Kiriu Mod Manager 0.0.10

- 修复 XXMI/游戏已启动却因输出内容混入回执而误报失败。Windows 启动回执使用独立文件，Launcher 不再继承管理器回执管道；没有收到回执时显示“启动状态待确认”，不将它认定为游戏启动失败。
- 新增通用提醒窗口，统一一次性操作成功、失败与确认反馈，默认支持一个或两个按钮；支持提示类型、标题、补充说明、默认/取消按钮和返回所选按钮索引。
- 提醒依次显示并合并相同待处理内容，支持 Escape、键盘焦点限制与恢复、长文本滚动和日间/夜间主题；内置网页在提醒期间让出显示区域。
- 包含 0.0.9 的路径兼容、EFMI/ZZMI 目录判定、手动安装提示与管理员授权启动修复。

接口见 [通用提醒窗口接口](../通用提醒窗口接口.md)。
