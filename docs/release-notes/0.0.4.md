# Kiriu Mod Manager 0.0.4

- 预设页加入独立配置档：选择 INI 捕获参数与热键，复制保存的配置，预览并切换；支持保存活动修改后切换，或保留恢复副本后切换。
- 增加 Mod 前置依赖、组件最低版本和兼容声明。主窗、浮窗、批量、互斥组、预设、配置切换、换包与恢复使用共同校验；已知缺失/低版本阻止启用，未知版本须本次确认，联动停用须明确接受。
- 支持手动检查已绑定 GameBanana Mod 的来源版本与文件变化，明确选择候选包下载，再从下载页查看 INI 差异、选择包内一个条目并确认替换指定 Mod。
- 换包保留 Mod 身份、名称、角色位置、用户信息、封面、收藏、标签和原启停状态；完整旧版与配置关联可恢复。新包使用新 INI，活动配置捕获新内容，其它旧配置须重新适配。
- 增加收藏、标签编辑、已有标签建议、收藏筛选、多标签交集筛选与标签搜索。收藏操作保留同 Mod 的作者、版本与标签草稿。
- 配置档切换采用可恢复文件队列；中断后到“备份与恢复”回退，外部修改导致不能可靠恢复时保留副本并停止覆盖。
- 加入扫描索引、封面缓存、长列表虚拟化和本地滚动操作日志。

绝区零和终末地共用 GameBanana 登录与浏览器，Mod 库和任务目标保持各自归属。新增在线安装仍默认停用；Mod 更新由用户逐步确认，外部网盘继续手动导入。下载校验不会把人工兼容性状态改成已验证。

- 第二批：设置新增环境诊断，按依据显示通过／问题／未知，支持预览后导出脱敏 Markdown 或 JSON 本地报告。
- 备份页显示占用、保护和配置引用；恢复前预览实际目录与文件影响，确认后重新校验。支持显式永久清理所选副本，中断后手动继续或撤回完整未删项目，不自动清理。
- 候选冲突页增加 INI 节、条件、命名空间、match／filter、资源／run 引用和文件行定位；可手动停用或维护互斥组，不自动判定游戏内冲突。
- Mod 列表支持最多三个主次排序条件，按游戏记住偏好，保持当前详情、草稿、多选与滚动锚点。

版本仍为 0.0.4。本地测试／源码窗口与真实游戏、新包和正式发行分别验收；详细限制见第二批功能验收文档。
