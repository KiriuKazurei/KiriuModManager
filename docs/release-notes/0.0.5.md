# Kiriu Mod Manager 0.0.5

- 完成游戏路径修复闭环：绝区零与终末地共用受限解析和候选选择，先预览再确认保存/同步，保留原字节副本；支持明确回退、中断待处理、剩余项预览和重试，保护外部设置修改及另一游戏的草稿。
- 加入开发端兼容测试 SDK 0.1.0：本机只读检测、稳定内容摘要、XXMI/Importer 来源检查、固定必需测试矩阵、分层报告和 compatible/incompatible/inconclusive 三态判定。
- 提供 inspect、run、watch、triage、baseline approve、recover 命令；前台轮询按构建去重，失败项针对性重试一次，确认缺陷后生成本地开发任务，通过不触发 Git 操作。
- SDK 专有工作区使用写前日志和摘要保护恢复；外部修改保留，未恢复现场阻止后续运行。提供 A/B/A 图像组合断言，缺失必需用例或证据时不报告兼容。
- 源码门禁独立执行类型检查、完整测试、API 清单、构建和隔离 Electron 窗口回归，不再依赖开发机的旧验收文件；回归脚本从 package.json 读取当前版本。
- 整合 Cursor/ui-better：主题从按钮中心圆形扩散；减少动画偏好使用淡入，不支持时直接切换；夜间悬停保留按钮强调色。
- 新增 SDK 0.2.0 显式进程范围：固定 Launcher 计划、专属进程树正常重启、异常退出恢复、SDK 中断收尾及持久记录；默认不启动游戏。
- 设置常规页新增进程兼容测试：导入本地 SDK 记录、核对当前游戏/XXMI/管理器指纹，区分通过、失败、证据不足、过期和未知；不改人工 Mod 验证。
- 同步使用说明、迭代进度和前后端对接资料。桌面 API 当前 99 个异步方法和 1 个事件；新接口只有记录读取/原生导入，不向网页或 renderer 增加任意文件/进程权限。

用户已将本轮 SDK 范围缩为进程重启/恢复，不做窗口捕获/输入、固定基准 Mod、加载效果或刷新。真实游戏/XXMI 的进程验收仍单独待执行；本地记录摘要不是远程签名。游戏发行版本没有可靠来源时显示未知，PE/XXMI 版本不冒充游戏版本。本版不宣称任意第三方 Mod 或两游戏已通过游戏内兼容测试。

本次交付为 0.0.5 源码提交，不包含便携包、GitHub Release 或真实游戏/XXMI 启动。源码推送本身不会使管理器更新器发现可下载的发行包。
