# Kiriu Mod Manager 0.0.9

- XXMI 路径兼容外层根目录、Resources、Resources/Bin 和 Launcher EXE；检测、启动和保存使用同一个外层根目录，已有内层目录配置无需重新填写即可识别。
- 游戏路径兼容外层安装目录、实际 EXE 所在目录与对应游戏 EXE；保存为实际 EXE 所在目录，启动和刷新按真实 EXE 比较，避免把同一安装的内外层目录误报为不同位置。
- 外层查找找到明确游戏目录后跳过其内部数据与备份；不同安装出现多个候选时仍需明确选择，不自动采用首个结果。轻检查保留目录项、深度和时间限制，链接及错误游戏文件继续拒绝。
- 更新路径字段说明，明确支持的位置和最终保存的目录。
- XXMI 需要管理员权限时，KMM 先提示并等待用户确认，再由 Windows 显示 UAC 权限请求；修复普通进程启动调用遇到 Windows 740 错误时直接失败的问题。取消授权与其它系统启动失败分别提示，保留 Windows 错误码。
- 游戏组件按 XXMI 根目录下的 EFMI（终末地）或 ZZMI（绝区零）目录判断，与 d3dx.ini/Mod 读取状态分别展示。缺少对应目录时仍可打开 XXMI；点击启动游戏也先打开对应 Launcher 页面，提示用户手动安装后重新检测，不自动安装组件。
