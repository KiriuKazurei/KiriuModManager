# Kiriu Mod Manager 0.0.12

- Mod 详情栏固定在右侧并独立滚动，窗口变窄时中间列表自适应缩小。
- 简化列表工具区，删除重复的结果行与独立排序行；排序、启停、收藏及标签筛选统一放入“筛选”。
- 彩色标签横向显示在 Mod 名称与状态之间，放不下时可通过“…”展开。详情栏支持手动添加标签，右键可重命名、选择背景色或删除。
- 标签和颜色保存在各 Mod 目录的 tags.json，沿用旧标签并支持重启恢复；导入替换和单项内容恢复保留当前标签。
- 列表启用与停用标志使用绿、红背景；详情栏切换按钮按动作显示绿、红边框；整行选中效果覆盖复选框与收藏区域。
- 调整角色列表字号，中间列表行高较本轮初始值累计减少 10px，并同步虚拟滚动高度。

验证：308 项回归测试、类型检查、接口清单及构建检查通过；真实 Electron 隔离窗口覆盖彩色标签编辑与重启恢复、筛选内排序，以及 900 / 1180 / 1600px 窗口下的布局和 102px 虚拟列表行高。

使用与存储边界见[模组标签与筛选](../模组标签与筛选.md)。Windows x64 便携包为 KiriuModsManager-0.0.12-win-x64.zip，配套 kmm-update.json 供管理器检查与校验更新。
