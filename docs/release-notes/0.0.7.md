# Kiriu Mod Manager 0.0.7

- 将路径配置统一为“路径设置”，检查与修复作为默认折叠的附属功能，保留候选预览、确认、修复与回退。
- 支持粘贴 XXMI Launcher 或对应游戏的 EXE 路径，保存时验证实际文件并转换为安装目录；旧配置中误存的 EXE 路径可通过再次保存修正。
- 保存时拦截文件误填、其它游戏 EXE、缺失游戏位置及上级路径为文件等情况；失败时保留已保存配置和当前草稿。
- 恢复路径字段说明和同步提示，明确管理器保存路径与 XXMI 实际读取配置之间的区别。
- 更新成功并确认新版窗口启动后，自动删除临时旧版程序；失败恢复旧版并显示更新失败提示，保留配置、Mod 与日志。
- 修复 Windows 更新 helper 进程返回成功但脚本未执行的问题；增加原生启动输出、提前退出检测和完整程序校验的准备等待。
- 保留完整运行依赖校验及跨盘 AppData 原子写入修复，避免安装升级后遗漏依赖或配置写入失败。

从 0.0.6 首次更新若提示 helper 未就绪，原程序会保持运行。本版已修正该启动故障；无法继续时可使用完整目录包完成首次升级。
