## 已实现的流程

`inspect` 对本机路径作只读检测，有限重试取得两次一致观察；分别保存内容构建摘要、路径/文件身份指纹、组件版本及来源。`run` 固定检查所选必需矩阵，对失败项仅重试一次，前后上下文一致且具备正常对照和证据才允许归类缺陷。源码/local 通过不能自动变成完整游戏兼容。

`watch` 在前台低频轮询，两游戏串行执行，通过安静，变化后持久去重；不稳定只记录待补测，不覆盖之前稳定构建。同一重复失败可生成一次本地 `task.json` 和 `fix-task.md`，不调用外部编码 Agent 或 Git。`baseline approve` 需要显式 reviewed、已通过的真实用例和完整截图/场景证据；当前默认 suite 因未接真实游戏而拒绝批准。

SDK 只在新建的自有 sandbox 中写探针/测试文件，写前保存日志和原字节。恢复核对本次写入摘要；外部修改保留，恢复未完成阻止下一轮。崩溃遗留锁不自动抢占。A/B/A 纯图像断言已有同窗口/场景、锚点、ROI、黑帧、恢复和独立加载信号组合检查；它不是窗口捕获实现，也不包含实际游戏阈值。

具体 Node 接口、每条命令对应功能、配置与限制见 [SDK 使用说明](../dev/compat-sdk/README.md)。总体设计与仍待完成的 S2/S4 见 [SDK 方案](版本兼容自动测试SDK与提示方案.md)。

## 当前真实环境事实与待办

终末地 config.ini 是不透明二进制，verify_files.json 是 move/patch 文件清单；发行版本保持未知。EXE 的 `2021.3.34...` 仅作为 PE 字段，不能当游戏发行版本。游戏内容证据只覆盖 EXE 和有限根清单/配置，不保证捕捉资源独立热更新。

给出的 EFMI 目录可识别为组件目录，父目录有 Launcher 配置。但标准 `Resources/Bin/XXMI Launcher.exe` 和 Launcher 包版本证据未找到；SDK 不替用户安装或改动它。该事实是本机接入条件不足，不能直接当管理器兼容缺陷。

S2 仍需开发并验收：可用 Launcher、与日常库隔离的 SDK XXMI/Mod 根、自有基准 Mod 与固定角色/场景、初始正常/失效样本、实际游戏窗口捕获/身份/输入、生命周期/A-B/A/刷新重启和进程恢复。未提供绝区零真实安装样本。S4 用户端提示、结论共享及外部 Agent 调度不在当前已完成范围。
