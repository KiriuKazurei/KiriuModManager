# 0.0.2 寻找 Mod：实现与验收

更新日期：2026-10-13。源码版本为 0.0.2，项目与锁文件一致。已完成内置浏览、独立下载分页、校验、手动一键停用安装和网站信息绑定；本轮未生成便携包、创建 Release 或运行真实游戏。功能依据见[迭代方案](寻找Mod功能迭代方案.md)。后续页面与手动安装调整以[下载页面迭代](0.0.2下载页面与手动安装.md)为准；下列旧报告记录的是调整前的自动安装流程。

## 使用方式

1. 在设置中保存绝区零的 Mod 目录。修改目录必须保存，不使用未提交草稿。
2. 点击左侧“获取Mod”，在原 GameBanana 网页搜索并打开 Mod，再点击所需文件的下载链接。
3. 点击左侧“下载进度”查看任务和完整包。校验完成后进入待安装，可点击“一键安装”，或“选择安装位置”逐项修改角色文件夹；安装完成后默认停用。
4. 点击任务中的“查看已安装 Mod”，打开当前库中的对应项，检查信息后再按现有互斥规则启用。

首页固定为 [GameBanana 绝区零](https://gamebanana.com/games/19567)。设置页不再提供可编辑 Mod 网页地址；旧 marketUrl 保存字段保留兼容，但不决定此入口。更新发布页设置和管理器更新器保持独立。终末地未指定网页，页面明确显示未配置；既有下载仍属于绝区零。

外站链接先显示在可信工具栏，用户明确点击“打开外部链接”后才提交给默认浏览器；外部网盘下载仍通过已有本地导入处理。广告子框架的跳转不当作主页面外部跳转，不绕过网站的登录或访问限制。

## 下载任务与安装目录

- 网站视图、Cookie 与下载使用独立持久 Session；网站没有管理器 preload、Node 或本地 IPC 桥接权限。
- 下载请求发出时记录来源详情身份，收到原生 DownloadItem 后建立任务；安装时再通过官方 API 核对游戏、文件 ID 和文件名。
- 最多三个活动下载；支持 ZIP、7z、RAR。任务显示目标目录、字节进度、阶段和逐项结果。
- 支持取消尚未提交安装的任务、重新下载、重读站点信息、使用完整缓存包重试安装，以及查看完整压缩包。
- 重新下载建立新任务并读取最新保存目录；缓存安装保留原任务目标。目录改变或尚未配置时进入 waiting-directory，用户明确确认“使用当前目录准备安装”后再次核对配置，仍须点击安装。
- 离开页面或切换游戏不把任务改装到另一游戏；新任务只读取绝区零的设置。修改配置不会搬迁原目录的 Mod。
- 历史任务位于旧目录时，查看已安装项的按钮提示需要先在设置中切回旧目录，不静默修改配置。
- 任务记录保存在用户数据的 mod-downloads/tasks.json，完整包保存在所属任务缓存目录；重启保留结果，活动任务改为 interrupted，不自动续装。
- 任务文件损坏时保留原文件并报告错误，不以空记录覆盖；缓存包缺失时不显示可用包。记录限制为 5,000 项和 16 MiB，首版不自动清理缓存。

Chromium 可能在用户导航时取消尚未收到文件响应的网页请求；尚未产生 DownloadItem 的请求不冒充已建立的下载任务。已经建立的下载/安装任务独立处理，其来源身份不依赖后来浏览的网页。

## 内容、信息与错误处理

核对站点文件大小，提供 MD5 时核对 MD5；没有摘要时明确说明只核对了大小。MD5 是与站点记录比较，不是作者签名，也不证明兼容性。下载包和解压大小限制为 2 GiB，解包沿用最多 50,000 个条目等安全限制。危险路径、链接、特殊文件、无 INI、损坏或需要密码的包不进入正常安装。

在线安装先解包并识别候选，再逐项检查同名冲突。每项在 Mod 根的同磁盘受控暂存目录准备完整内容，提交为 DISABLED_ 目录，并原子保存注册表中的稳定 ID、metadata、provenance 与 remote 绑定。元数据保存失败时撤回本项新内容；无法撤回时明确报告实际位置。原子 JSON 替换在 Windows 短暂占用时有有界重试，不通过删除原 JSON 规避锁。

同名项不覆盖，后续候选继续处理；成功与失败同时显示。重复识别使用当前库有效记录的站点 Mod ID、文件 ID 和包内条目身份，因此改名/分类后仍能识别，同一包部分失败时重试只补缺失项。它不是全库内容指纹检测。

站点绑定包括标题、作者/提交者、简介、原分类、文件 ID、文件名、下载地址、大小及可用摘要。已识别角色采用现有别名表，未知角色不猜测。provenance 记录来源、站点版本和导入时间，适用游戏版本留空、验证状态仍为 unverified。包内已有本地预览继续由现有库识别，本轮不额外抓取在线封面。

站点信息在详情中只读展示；用户可编辑现有作者/说明及来源/版本表单。改名、分类、启停、预设和重启保持绑定。本地替换清除当前内容的文件级绑定、重置版本与验证状态，旧绑定随替换前副本保留；恢复和快照可以恢复对应绑定。新 Mod 不自动加入预设或互斥组。

安装阶段进入现有文件队列；退出等待已经开始的提交结果，网络任务中断并记入记录。活动 Mod 任务期间拒绝安装管理器更新；更新安装或退出期间拒绝新任务。

## 接口与源码

新增五个异步接口，当前合计 **55 个异步方法 + 1 个可解除事件**：

| 方法 | 通道 | 行为 |
| --- | --- | --- |
| setModBrowser(game,bounds|null) | market:view | 固定网站视图显示/隐藏，区域限制在窗口内 |
| modBrowserStatus() | market:status | 响应式网页、外部链接和下载任务状态 |
| navigateModBrowser(action) | market:navigate | back/forward/reload/home/external；外部 URL 只取主进程已保存的待打开链接 |
| modDownloadAction(id,action,destinations?) | market:download-action | cancel/retry-download/retry-binding/retry-install/install-current/show-file；只接受本地任务 ID，安装选择允许受控相对文件夹，不接受任意绝对路径或下载 URL |

| modDownloadInstallPlan(id) | market:install-plan | 返回逐项角色匹配及可选文件夹，预览不安装 |

详情见[权威接口文档](桌面接口文档.md)和[AST 清单](desktop-api-inventory.json)。这些接口只向可信主窗口开放，远程网站和浮窗不能使用它们。

核心模块：gamebanana.ts（站点解析/绑定/校验）、mod-downloads.ts（任务和持久化）、mod-browser.ts（原生视图/导航/下载事件）、mods.ts（逐项提交和库绑定）、atomic-json.ts（原子 JSON 写入）。页面使用 ModBrowserPage、ModDownloadsPage 与现有 Mod 详情，设置继续使用 saveGamePaths。
