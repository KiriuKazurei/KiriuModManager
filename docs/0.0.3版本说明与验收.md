# 0.0.3 版本说明与验收

更新日期：2026-10-13。项目和锁文件版本为 0.0.3；更新资产脚本默认读取[0.0.3 更新说明](release-notes/0.0.3.md)，保留显式 notes-file 参数。

## 页面与行为

- 终末地“获取Mod”打开 [GameBanana 终末地主页](https://gamebanana.com/games/21842)，绝区零继续使用 games/19567。
- 按后续 Cookie 要求，两款游戏共用同一个沙箱网页视图、导航历史与登录状态；切换游戏加载对应主页，离开页面只隐藏视图，退出释放视图。每款游戏的首页按钮返回自己的主页。
- 保留既有 `persist:kmm-gamebanana` Cookie 分区，普通 Cookie 遵守网站有效期；会话 Cookie 在本机加密保存并于启动恢复。登录轮换和退出删除会更新保存记录，账号有效性仍由网站决定。详见[内置浏览器与登录保存](内置浏览器与登录保存.md)。
- 按后续明确要求，终末地与绝区零共用托管下载、文件大小/摘要校验、网站信息绑定、角色匹配和下载页安装流程；下载完成等待用户一键安装，安装后默认停用。每项任务按所属游戏使用设置根目录，切换游戏不改变下载、重试或安装归属。“查看已安装 Mod”切到任务所属游戏的库。
- 设置页新增“常规设置”和“关于”分页，可用方向键、Home、End 切换。路径、桌面设置、更新源及版本说明状态在分页切换时保留。
- 关于展示实时应用版本、检查更新、获取更新、更新说明和更新源配置；沿用原更新器的原生确认、包校验与退出安装机制，不额外创建更新流程。
- 没有发现新版本时获取更新不可用；未保存的更新源须先保存再检查。源码模式保留原保护，不能下载并替换工作目录中的程序，页面明确显示说明。
- 主窗口主题标题栏与设置页快捷操作保持；默认停用的 Mod 安装规则保持。

## 接口与兼容

异步接口仍为 **55 + 1 事件**，见[权威接口文档](桌面接口文档.md)及[自动清单](desktop-api-inventory.json)。

ModBrowserStatus 新增 gameId，表示当前工具栏游戏上下文，前端忽略切换后收到的旧游戏状态；共享浏览器后退可显示另一游戏页面，downloads 内每项仍有独立 gameId 和目标目录。旧 openLink(game,'market') 兼容入口支持两款游戏并使用所请求游戏的固定主页。下载绑定增加内部 gameId 校验，旧绑定缺少字段时按原绝区零记录读取；库记录继续兼容现有数据。
