# 0.0.2 窗口与设置入口调整

更新日期：2026-10-13。本次仅调整主窗口标题栏与快捷操作位置，源码版本仍为 0.0.2。

- 主窗口采用隐藏标题栏与原生窗口按钮，隐藏可见窗口名称；左上角 KIRIU 品牌保留。
- 顶部空白标题区域随日间/夜间主题同步颜色，可拖动窗口；最小化、最大化和关闭按钮保留。
- 顶栏保留主题切换、打开 XXMI 和启动游戏；请求刷新与原“更多”菜单移至设置页“快捷操作”。
- 设置页快捷操作为请求刷新、打开 Mod 网页、打开更新发布页、退出管理器。保留原行为、选中游戏、失败提示与正常退出等待流程。
- 远程浏览器区域随新增标题区域布局调整，离开浏览页面仍释放显示区域。

新增 `setWindowTheme(theme:'day'|'night')` / `desktop:window-theme`：可信主窗口通过固定主题枚举同步原生标题栏背景和按钮颜色，不接受任意颜色或窗口 ID。浮窗及远程网页无此权限。当前接口总数为 **55 个异步调用 + 1 个事件订阅**，详见[权威接口文档](桌面接口文档.md)和[自动清单](desktop-api-inventory.json)。

实现使用 Electron 的[自定义标题栏](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)，保留原生窗口控制按钮。视觉上不显示窗口标题，系统用于任务切换的窗口名称仍保留。

验证：类型检查、构建、55 + 1 API 检查和 **76/76 既有测试通过**。[实际窗口报告](../.run-data/window-chrome-smoke/run-fidNlO/report.json)覆盖两种主题同步、Windows 原生标题区域命中、无可见标题文字、设置页入口、无效主题拒绝、原生浏览器区域及正常退出。[日间窗口](../.run-data/window-chrome-smoke/run-fidNlO/main-day.png)、[夜间窗口](../.run-data/window-chrome-smoke/run-fidNlO/main-night.png)、[设置入口](../.run-data/window-chrome-smoke/run-fidNlO/settings-day.png)为实际桌面截取，包含原生窗口按钮。

刷新测试使用未安装 loader 的隔离样本，验证原服务错误反馈；外部发布页打开由特权 driver 记录，不启动默认浏览器或真实游戏。未重新验证网站下载、打包或正式发布。

重复窗口检查：`npm.cmd run smoke:window-chrome`。
