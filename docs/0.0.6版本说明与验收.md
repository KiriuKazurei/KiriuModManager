# 0.0.6 版本说明与验收

日期：2026-10-16。管理器版本为 **0.0.6**，开发兼容测试 SDK 保持 **0.2.0**。本版在开发基线 `6a38e32` 上整合统一日志、默认 Mod 目录与品牌图标调整；实现分支为 `agent/diagnostic-logging`，按开发约定回流并推送 `agent/main`，保留功能分支。实际提交与远程结果以 Git 引用为准。

## 功能与业务边界

- 统一日志：通过操作切面和异步上下文关联 IPC、父子操作、后台任务、文件事务检查点及结果；补齐可信界面控制元数据、JS 错误、未处理拒绝、Electron 渲染／子进程退出与会话异常结束记录。远程网页不获得桌面接口。
- 日志与诊断：默认安装目录 `log`，不可写时明确回退到 `userData/log`；两处不可写时报告健康状态并保留有界内存记录。支持 JSONL 轮转、脱敏、本地致命错误记录和关闭上传的 Crashpad。设置 → 诊断 → 日志可打开实际目录及分析当前游戏／共享事件。
- 分析与追溯：保留时间、会话、请求／父操作／任务等引用，分析冲突候选、下载／校验、空间／权限／占用、崩溃和未完成操作。分析范围有界并展示截断／坏行；事务恢复仍以持久恢复记录为准，不自动认定所有故障的根因。
- 默认 Mod 目录：新配置／空路径在管理器目录创建 `Mods/ZZZ` 与 `Mods/Endfield` 并原子保存；已有自定义目录保持。在设置中清空 Mod 路径恢复默认值，不移动已有文件、不自动同步加载器。
- 更新协调：保留安装目录 `Mods`、`log`，拒绝更新包／清单夹带用户目录；更新辅助程序记录已转移目录，失败时随旧程序回退。
- Logo 与图标：侧栏品牌为 ModManager，标记 36×36、700 粗体 K、主题色字母及 2px 直角边框；浅色底色为 `#596273`，深色沿用 `accent-ink`。托盘与任务栏使用统一深底图标，提供源码与生成脚本。

详细接口及数据保留规则见[桌面接口文档](桌面接口文档.md)、[GUI 对接文档](前端功能接口调整需求.md)及[统一日志说明](本地操作日志.md)。当前桌面 API 为 **102 个异步方法 + 1 个事件**，其中 96 项有界面消费者、6 项兼容保留；新增 `logReport`、`openLogDirectory`、`reportRendererEvent` 三项日志接口。
