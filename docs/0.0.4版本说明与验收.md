# 0.0.4 版本说明与验收

更新日期：2026-10-14。项目及锁文件版本为 **0.0.4**。本次实现第一批高优先级 F05、F06、F08、F09、F10；完成项从待迭代总表移出，第二、三批与独立验收事项继续保留。

## 使用与实际行为

| 功能 | 入口与行为 |
| --- | --- |
| F05 独立配置档 | 预设页输入名称，捕获选定成员的 INI；现有启停预设也能捕获配置。保存当前状态只保存成员启停，保存当前配置显式创建 INI 修订。复制读取保存的副本。切换前预览、处理活动修改、确认版本提示；切换前保存完整恢复副本 |
| F06 依赖与兼容 | Mod 详情“依赖与兼容声明”选择当前库前置 Mod，维护最低版本、组件要求、游戏版本、声明来源及备注；“检查启用条件”展示本机版本及问题。缺失、停用或已知低版本阻止启用；版本未知与文字兼容范围要求本次确认 |
| F08 手动 Mod 更新 | Mod 详情“Mod 更新”检查当前或多选项；来源必须与网站绑定一致。显示来源声明更高版本、同文件变化、其它文件选项及错误。选择候选后确认下载；下载页查看原/候选版本、INI 新增/移除/改变、活动配置影响，明确选择一个包内条目并确认替换 |
| F09 收藏 | 列表星标与详情收藏按钮，和角色、分类、启停、搜索条件一起筛选；按稳定 Mod ID 保存 |
| F10 标签 | 详情编辑逗号分隔标签，提供已有标签建议；多个筛选标签取交集，搜索包含标签；库中大量标签只展示最多 24 个可搜索建议，依赖列表延迟展开并使用虚拟列表。最多 20 个、每个 40 字符，NFC 规范化并忽略大小写去重，保留显示写法 |

依赖不会自动开启前置；缺少前置时先手动解决。停用/移除前置及互斥切换影响依赖者时，提示联动停用并要求明确接受。启用前置在依赖者之前，停用依赖者在前置之前。新在线导入仍默认停用，定向更新保持原启停状态，重新校验依赖；下载摘要通过不会改成人工“已验证”。

预设成员编辑和 INI 编辑器草稿须先保存。编辑器关闭、重读或切换文件时提示放弃未保存内容。切换配置时可保存活动配置的当前启停与 INI，再切换，或仅保留恢复副本后切换；取消不提交。删除配置关联须确认，当前 INI 和历史配置副本保留。

## 文件与兼容约束

- `library-<game>.json` 增加可选 `favorite`、`tags`、`contentRevision`、`requirements`、`activeProfile`；旧库自动获得稳定内容修订，收藏默认否、标签默认空。根目录改变先保存旧库索引，新根不沿用活动配置；旧预设被覆盖时也保留旧根索引。
- `presets-<game>.json` 保留原启停预设，新增 `mode: profile` 和不可变修订引用；一般预设编辑、加入成员不会丢掉配置引用。
- 配置保存在 `profiles/<game>/<presetId>/<revision>/manifest.json` 与摘要命名的字节副本；验证游戏、根、成员 ID、内容修订和 SHA-256。每个 INI 不超过 4 MiB，捕获总量不超过 64 MiB / 2048 文件。未选 INI 继续共享，未捕获成员显示提示。
- 配置只在进入配置页、预览、保存及恢复边界校验磁盘摘要；不在每次库扫描中读取全部 INI。Mod 内容替换后，旧修订禁止直接写回，须先适配并重新捕获。
- 本机组件版本仅从所选 XXMI 的 `Resources/Packages/{Launcher,XXMI,ZZMI或EFMI}/Manifest.json` 读取；缺失/无效为未知，不用远程最新版冒充安装版本。普通数字版本可比较，自定义/预发布文本不猜测大小。
- 更新最多三个并发信息请求，同一来源合并查询；单来源超过 200 个文件选项时要求人工核对，候选缓存也有上限；没有轮询升级。候选及确认有有效期，检查前后核对根、内容修订和绑定；下载任务持久化目标 ID、游戏、根、原内容修订及候选指纹。目录或目标已变化时停止定向安装并保留包，不能套用新安装的改根路径。
- 更新保留用户名称、角色位置、信息、封面、收藏、标签。完整原文件/网站绑定/配置关联先保存；新 INI 使用新包内容。活动配置捕获新内容，其它配置保留旧修订并提示适配。单 Mod 内容恢复保留当前收藏/标签，已移除项取副本值；完整快照恢复快照值。
- 配置切换采用 v2、INI/移动/元数据共用的可恢复记录，保持 v1 记录可读；先完整准备再提交，回退先恢复目录位置再还原 INI。外部修改使回退不可靠时，保留副本、阻止继续操作该根，去“备份与恢复”处理。完整快照包含当前游戏配置目录；旧快照没有配置时清除无效活动关联。
