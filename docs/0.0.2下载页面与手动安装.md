# 0.0.2 下载页面与手动安装

更新日期：2026-10-13。根据用户最新调整，将网页浏览和下载资源管理拆开，并停止下载后自动安装。源码仍为 0.0.2。

## 使用方式

1. 在设置页面保存绝区零 Mod 根目录。
2. 点击“获取Mod”浏览指定 GameBanana 网页。工具栏采用后退、前进、SVG 刷新、首页、可复制地址栏和下载入口；右侧栏已移除，网页使用完整内容区域。
3. 在“下载进度”管理进行中任务、待安装资源、已下载包、安装结果与历史记录。支持取消、重试、查看压缩包及记录筛选。
4. 完整包通过大小及可用摘要核对后进入待安装，下载和重读网站信息都不会自行安装。
5. 点击“一键安装”使用自动匹配位置；点击“选择安装位置”查看逐项建议，可从已有分类/角色文件夹、根目录中选择，或使用原生文件夹选择器。
6. 安装完成后默认停用。通过“查看已安装 Mod”进入对应详情，按现有启停与互斥规则手动开启。

## 文件夹匹配与安装规则

- 优先按包内条目名称、已有路径、网站角色分类及已知角色别名匹配。多 Mod 包分别匹配；未知或多个角色线索不强行认定角色，可手动选择。
- 已有角色目录优先复用，例如 Anby 或收藏/艾莲。没有明确已有位置时建议“分类/角色”；无法识别角色时使用网站已映射分类或根目录。
- 手动选择只允许任务 Mod 根目录下的相对分类/角色文件夹，拒绝绝对/越界路径、链接、隐藏或资源目录及另一个 Mod 内部目录。根目录调整仅在设置页面进行。
- 已保存根目录改变时，任务进入等待目录选择。确认“使用当前目录准备安装”只更新此任务目标并重新校验，仍需要点击安装，不搬迁已有 Mod。
- 安装前再次校验缓存，进入文件队列受控解包与逐项提交。每项使用 DISABLED_ 前缀，同名目标不覆盖；已有效安装的站点文件条目保持原内容和用户状态。
- 稳定身份、作者/来源/版本和站点绑定继续保存；预设、互斥、替换和恢复规则沿用现有实现。
- 重启保留待安装资源与历史记录，正在进行的任务标为中断，不自动安装或恢复下载。首版仍不提供断点续传和自动清理缓存。

## 接口变化

当前 **55 个异步调用 + 1 个可解除事件**，详见[权威接口文档](桌面接口文档.md)和[自动清单](desktop-api-inventory.json)。

| 接口 | 行为 |
| --- | --- |
| modDownloadInstallPlan(id) / market:install-plan | 从所属完整包生成 targetRoot、folders 和逐项 entryPath/name/character/folder；预览不安装 |
| modDownloadAction(id,action,destinations?) | 缓存安装允许逐项 entryPath/folder 选择，主进程校验完整性、边界及文件身份；retry-binding 仅准备，install-current 仅确认根目录与准备 |
| modBrowserStatus() | 下载阶段新增 ready，保留旧记录兼容；网页与下载页分别消费状态 |

页面为 ModBrowserPage 与 ModDownloadsPage。安装位置计划进入已有文件队列，网络下载保持独立。上述接口仍只允许可信主窗口，网站无桌面桥接权限。
