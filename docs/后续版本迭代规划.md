## 第三批：后续迭代

完成统一导入预检／内容去重、通用预设应用前预览，以及跨库清单导入导出。第一批所需的特定操作确认不等于这些通用功能已完成。

### F01：导入预检与内容去重

- 当前基础：已有在线角色匹配、安装目录选择和同名保护；文件夹及 ZIP／7z／RAR 可导入。
- 迭代范围：统一本地与在线导入预检，展示包内内容及识别出的 Mod，选择待安装项，确认角色和目录；显示解压体积与可用空间；按内容指纹提示异名重复。
- 验收重点：预览仅写有归属的准备缓存，不提交库文件；同名原内容继续保护；重复和识别不确定项由用户明确处理；保留归档安全校验与逐项结果，新本地导入及在线安装统一默认停用。

### F02：预设应用前预览

- 当前基础：预设保存成员启停选择，互斥冲突时要求明确选择。
- 迭代范围：应用前完整展示将启用、将停用、保持不变、缺失成员、父目录阻挡和互斥组问题，用户确认后执行。
- 验收重点：预览不改目录；确认执行时根据最新已保存目录与实际文件重新校验；预设外成员默认保持，互斥／依赖联动逐项展示并确认；提交失败可回退，结果如实报告。

### F12：预设清单导入导出

- 当前基础：预设在当前库内按稳定 ID 保存，无跨库清单迁移流程。
- 迭代范围：导出方案名称、来源链接、版本与启停选择；另一台机器或库按内容和来源匹配本地 Mod，提示缺失或歧义项；衔接 F05 已有捕获／切换流程，新增可移植 INI 配置导出和非活动接收。
- 验收重点：跨库映射到本地身份，导入前显示影响；未知来源、版本不符和缺失成员明确处理；格式可版本化，导出内容经过隐私核对。
