# 0.0.5 版本说明与验收

日期：2026-10-15。管理器版本为 **0.0.5**，开发端兼容测试 SDK 为 **0.1.0**。本版将本地路径修复提交 `5b0a169` 和随后 SDK 基座、自动化、文档及发布整理一并同步到远程源码。此前 0.0.4 的功能和测试记录保留为历史证据。

## 功能与接口

产品侧提供双游戏路径检查/候选发现、确认修复、范围预览、同步及可恢复回退。回退失败保留待处理状态，后续预览只显示剩余项，设置竞争不会覆盖外部新值。实际行为见[路径修复与验收](0.0.4路径修复与验收.md)。

开发侧提供[SDK Node/CLI 接口](../dev/compat-sdk/README.md)，覆盖本机只读版本/组件检测、有限稳定观察、内容构建标识、固定分层矩阵、报告、受控重试、SDK 专有工作区恢复、前台轮询/持久去重、本地缺陷任务及显式基线批准。源码门禁现在每次独立运行源码窗口测试，不依赖开发机旧 `.run-data`，新拉取源码可生成自己的门禁。

桌面契约保持 **97 个异步调用＋1 个事件**；91 项有 renderer 消费者，6 项兼容保留，25 个业务组件。SDK 没有 window.kmm 方法或产品页面，不改变人工 verification、Mod 启停、互斥或预设。对应功能、精确签名与 GUI 调整约束见[桌面接口文档](桌面接口文档.md)和[GUI 对接文档](前端功能接口调整需求.md)。
