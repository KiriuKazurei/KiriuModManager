## 1. 当前入口与兼容关系

| 旧入口 / 行为 | 当前页面入口 | 兼容与迁移要求 |
| --- | --- | --- |
| saveSettings(settings) 全量保存 | SettingsPage.saveGamePaths；DesktopSettings/AppUpdatePanel.saveDesktopPreferences | 旧方法兼容，完整替换且不能称并发安全；新方法在主队列读最新值后合并 dirty patch |
| importMods 原生直接导入 | 角色概览/ModPage/下载新装共同 ModImportPanel | 旧方法兼容同一 ImportPlanner 默认原生计划；GUI 用 prepare/revise/files/commit/discardModImport，支持修改与预检 |
| 下载新装 retry-install | prepareModImport(game,{kind:'download',taskId}) | 主进程拒绝旧新装绕过；定向更新仍使用 modDownloadInstallPlan + retry-install |
| applyPreset 直接应用 | PresetApplyPanel 的 preparePresetApply → commitPresetApply | 旧方法仅兼容，主窗原生确认；新 GUI 先展示完整最终状态/缺失/互斥/联动/排除；独立 INI 不走普通预设 |
| conflicts 直接报告 | ConflictPage 的 startConflictInspection → readInspectionJob → conflictDetails | 旧方法兼容；新报告含 type/hash、digest、上下文/未知/完整性及分页定位 |
| recovery/restore 直接恢复 | RecoveryPage 的 startRecoveryInventory、prepareRecoveryRestore → applyRecoveryRestore | 旧方法兼容；恢复范围/空间、保护、清理计划及持久任务走专用接口 |
| 更多/请求刷新顶栏 | 设置常规快捷操作 | 打开 Mod 网页进入内置获取Mod；更新发布页在外部浏览器打开；退出沿桌面 API |
| 设置里的市场 URL | 两游戏固定 GameBanana 首页 | marketUrl 字段兼容保留但不控制入口；共享浏览器/历史/Cookie，任务/库仍按游戏隔离 |
| 只有更新发布页链接 | 设置关于 → AppUpdatePanel | updateSourceUrl 是管理器更新源，updateUrl 是外部发布页；显示版本/说明、确认下载校验/安装，源码不安装 |

六项无当前 renderer 消费者的兼容方法为 saveSettings/importMods/applyPreset/conflicts/recovery/restore，其余 87 项已连接。不要为改布局恢复调用旧接口或臆造新 REST 路由。

## 3. 局部保存与草稿示例

相关 helper 已在 settings-draft.ts 接入；同身份外部刷新采用未编辑字段、保留 dirty 字段。自己的保存只接受提交且等待期间未再编辑的值。捕获操作游戏身份，不因异步返回改变当前选择。

```ts
const game = selectedGame;
const submitted = dirtyPatch(configuration.draft.games[game], configuration.baseline.games[game]);
if (!Object.keys(submitted).length) return; // 页面反馈“无待保存更改”
const result = await window.kmm.saveGamePaths(game, submitted);
if (!result.ok) { setError(result.error); return; } // 保留草稿
setConfiguration(previous => acceptSubmittedGamePaths(previous, result.value, game, submitted));
onSaved(result.value);
```

DesktopSettings 用 dirtyPatch/acceptSubmittedPreferences；关于页只保存 updateSourceUrl。省略字段保留、空字符串清空，undefined 不清空；空/未知/错误 patch 整体拒绝，不写文件或广播。selectGame 独立保存所选游戏。检测仅返回识别结果，路径保存不自动同步 XXMI。

事件 DesktopChange.gameId 是发通知时当前选中上下文，不是操作参数；settingsChanged 仅重读设置。成功/错误/原生取消/部分成功必须看当次 Result。onDesktopChange 返回解绑函数；不能让通知丢弃同身份详情/来源/设置/INI 草稿。页面目前真实挂载与可保留范围见 GUI 文档，不承诺所有表单全局持久保存。
