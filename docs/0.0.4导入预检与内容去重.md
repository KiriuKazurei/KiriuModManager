# 0.0.4 导入预检与内容去重（F01）

日期：2026-10-15。版本保持 **0.0.4**，接续已完成的 F02/F12；本轮覆盖本地文件夹／ZIP／7z／RAR 与 GameBanana 已下载新 Mod 的统一预检。定向更新／替换继续使用原流程。

## 使用流程

Mod 库角色概览、全部／角色 Mod 页的“导入文件夹”“导入压缩包”，以及下载页的“预检安装”，均进入同一面板：

1. 原生选择来源或固定下载任务，复制完整来源快照到当前任务自己的准备缓存，安全解包后识别 Mod。
2. 查看条目、原始路径、INI／文件数、逻辑体积、完整 SHA256、角色建议、网站绑定、重复与冲突。文件清单每页 100 项。
3. 选择包内部分条目，编辑名称和根目录内的相对分类／角色目录；也可通过原生选择器选择已有文件夹。改动后先“更新导入预检”。
4. 预检有效且无所选阻挡时，确认导入所选项。原生再次显示所属游戏、固定根、条目、跳过数和空间估计。
5. 结果逐项显示已导入／已有内容／已跳过／失败／未执行。**所有新项默认停用**，后续手动启用仍走依赖和互斥校验。

预检写自己的准备缓存；下载校验／准备失败时更新该任务的错误记录并保留完整包，便于重新预检或下载。不修改 Mod 库、现有 INI、预设、标签、收藏或兼容性。原生取消确认保留有效预检，可再次确认。关闭立即退出面板，受控缓存清理在后台完成，快速重开不会被旧关闭响应清空。长准备由共享后台任务承担，导航和进度保持响应；实际提交进入主文件队列。

## 内容与去重规则

- 复用 F12 的 `mod-tree-v1`：只去掉最外层目录名，比较内部路径与全部普通文件的原始字节；更改 INI、封面、资源都可能改变摘要。
- 完全重复内容默认不选择；仍想另存时，明确勾选“仍另存副本”，选择不同名称或目录，再更新预检。不会合并现有 ID 或改写整理信息。
- 相同网站 Mod／文件／条目仅表示已有来源关联。只有本次完整内容摘要一致才显示完全重复；本地改过配置的关联项继续保留，可明确另存，不自动升级。
- 同名、启用／停用名称变体、Unicode 等价目标及本次选择间的冲突均不能覆盖。默认跳过存在阻挡的项，可修改后重新选择。
- 删除标记、物理目录缺失和旧根记录不充当当前副本。旧内容缺失后重新导入同名项会得到新 ID；以后启用也不会复用旧 ID，旧预设保留缺失关联。
- 根 INI 与子 Mod 混合，或根有共享资源时，保留整体候选并提示复合包；不拆掉共享资源。单独可识别的多个 Mod 可选子集。无有效 INI 的来源拒绝导入。
- 新记录包含新本地 ID、内容修订、导入时间，以及已验证的网站绑定／来源版本；人工兼容性仍为未验证。

## 快照、空间与提交

任务固定游戏、已保存根、来源与快照摘要、库内证据及下载绑定。结果会话十分钟，确认凭证两分钟；每次修改选择生成新凭证，旧凭证失效。根、来源、库内容或缓存改变时重新预检；下载任务根改变先进入“等待选择目录”，原压缩包保留，明确改用当前目录后再生成新计划。

初始上限：32 个来源、100 个候选、单包 50,000 项／2 GiB、32 层、准备缓存合计 8 GiB／200,000 项；候选内容哈希 8 GiB 预算，库内完整内容比较另限 2 GiB／200,000 文件。超限或读取失败明确显示错误／未完成比较。未知比较不等同于没有重复。

快照前按实际文件夹或安全归档列表估计缓存卷空间，包含原压缩包副本、解包内容和 64 MiB 余量。预览显示目标卷需要的所选内容与余量；本轮直接由准备缓存复制到 FileOperations 的目标卷 incoming，随后改名提交，不再额外复制一份目标暂存。每项提交前重新查空间。空间无法读取时显示未知，用户需明确接受估计边界；已知不足时不允许提交。

逐项使用已有 `newOnly` 可恢复提交。即将发布的 incoming 内容再核对完整哈希，元数据采用预期摘要防止准备期间覆盖外部编辑。成功才发布该项记录；失败回退当前项，停止剩余项并报告，已完成项保留。停止提交在完整条目边界生效。

准备缓存位于 `userData/import-preparations/<UUID>`，带归属记录。关闭／取消可删除当前明确归属且无未完成提交引用的缓存；归属不符或可能被引用时保留。重启把未结束准备标为中断，不自动安装；原文件与完整下载包保持。恢复空间页盘点并提供缓存位置查看，跨重启或不明缓存不加入原恢复副本永久清理白名单。

## 下载与原功能兼容

两游戏下载共用同一预检组件与服务，固定任务自己的游戏／目录／绑定。确认后下载任务显示安装中；中断重启标为已中断，不自动继续。部分安装记录已完成 ID，下载记录显示部分完成；再次预检时重新比较当前内容，已有相同项默认跳过，可只安装剩余条目。全部未选时保持待安装；尚无完成项的明确停止显示已中断，不冒充安装失败。完整包一直保留。

旧 `importMods` 保留原生默认计划确认兼容入口；当前页面均已迁移。旧新安装 `modDownloadAction(retry-install)` 在桌面入口返回需使用统一预检，不能绕过界面安装；定向更新继续使用该操作并保留原身份／启停与备份。预设清单“导入替代”同样通过 ImportPlanner 与原生确认，不能在导入过程中自动应用预设。

新增五个主窗接口，当前 **93 个异步方法 + 1 个事件**：`prepareModImport`、`reviseModImport`、`modImportFiles`、`commitModImport`、`discardModImport`。主窗原生选择器决定来源；前端仅传类型／下载任务 ID、会话／条目 ID、受限相对目标和选择，不传任意文件路径。远程网页与浮窗均不能调用。
