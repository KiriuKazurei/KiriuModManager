# 下载暂停、继续与断点续传

范围：下载中心中的 Mod 新安装包和 Mod 更新包。沿用现有 GameBanana 会话、来源绑定、2 GiB 上限及安装预检；管理器自身更新包不在本次范围。暂停不安装，重启不自动联网续传，取消不等同于暂停。

实施顺序：底层片段与来源校验 → 下载任务状态和重启恢复 → 现有 IPC 操作扩展 → 下载页按钮与筛选 → 原生 Electron 和页面验收。

1. 下载过程中分段保存自有缓存中的恢复片段，原子保存字节偏移、SHA-256、URL 链、ETag、Last-Modified、长度及开始时间。任务不接受界面传入文件路径或任意下载 URL。
2. 暂停先停止网络读取并落盘恢复数据，再释放原生下载；保留原任务 ID、游戏、安装目录和更新目标。活动下载最多三个，暂停任务不占用下载名额。
3. 继续前复核片段摘要、网站文件身份和服务端 Range 响应；服务器不支持或资源改变时保留片段，明确要求重新下载，不能将新旧资源拼接。
4. 使用 Electron Session.createInterruptedDownload 恢复原任务；原生恢复回调没有 WebContents，必须以内部登记任务和精确缓存路径匹配，不放宽普通网页下载的来源检查。
5. 正常退出先保存片段；异常退出以最后完整落盘记录为准。旧版记录仍可读取，没有充分恢复信息时只提供重新下载。最终完整包仍执行网站大小和摘要校验，再进入既有安装预检。
6. 下载页增加暂停、继续、已暂停筛选及可读原因；重复点击、校验中暂停、取消和目录变化均由主进程再次检查。一次性失败使用通用提醒窗口。

验收：两游戏的新安装及更新包；暂停后字节停止增长；恢复后内容哈希一致；跨重启和进程异常退出恢复；不支持 Range、ETag/长度/站点绑定变化、片段缺失/损坏；三个并发任务上限；取消与退出；安装根变化和旧记录读取；真实 Electron 的部分文件、Range 和恢复事件；实际下载页按钮和提示。

官方 API：[DownloadItem](https://www.electronjs.org/docs/latest/api/download-item)、[Session.createInterruptedDownload](https://www.electronjs.org/docs/latest/api/session#sescreateinterrupteddownloadoptions)。续传能力取决于服务器提供的 Range、ETag 与 Last-Modified 信息，无法证明时显式重新下载。
